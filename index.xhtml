專業／戰術級品牌(歐美)

這類品牌多被軍警、保全、專業人員採用，強調極致可靠度與長期使用壽命，價格通常較高。

  • SureFire(神火) :美國品牌，戰術手電筒的標竿之一。以高強度、精準光型（高candela遠射）、軍規級耐用度聞名。適合真正需要「關鍵時刻不能掛」的用途。
  • Streamlight :同樣是美國專業品牌，在執法單位普及率很高。優點是可靠度接近SureFire，但價格親民許多，且常有雙燃料（可充鋰電＋CR123A）設計，終身保固也是一大優勢。光型偏向實用平衡，適合執勤、巡邏、居家防衛。
  • Maglite :經典美式手電筒代表。鋁合金筒身厚實、耐摔，傳統形象很強。現代LED版本已改善亮度與效率，適合放車上、家中當「備用工具燈」，但論輕便、高亮度、充電便利性，已不如新興品牌。
  • Armytek :手電筒領域中以「極致耐用、專業導向」聞名，嚴格來說是加拿大、歐洲與俄羅斯混血技術產品，耐用/可靠性非常好的品牌之一。

高性能市場主流(中國)

這些品牌在戶外、EDC、戰術領域有穩定口碑，做工、散熱、防水、保固都較完整。

  • Fenix(菲尼克斯) :綜合評價極高。恆定亮度電路、堅固鋁合金、USB-C 充電、介面直覺。適合日常攜帶與戶外。價格中高，但耐用度與售後服務優秀。
  • Nitecore(奈特科爾) :創新花樣功能多（OLED 顯示、MCT色溫與CRI切換、多光束切換、戰術模式等）。亮度與拋射（throw）表現出色，但部分款式介面較複雜，需習慣。品控、耐操上輸Fenix、Olight這類大廠。
  • Olight(傲雷) :外觀時尚、磁吸充電極為方便（懶人最愛）、體積小巧。Baton 與 ArkPro 系列是 EDC 熱門。有些款式僅支援MCC(他們家的磁吸充電)要注意方便性考量。
  • Acebeam :高亮度與拋射能力突出。性能導向，適合想要「亮又遠」的人。

玩家級(有保/中國)

這些在經銷商有保固，價格較低一些的強勢品牌手電筒。

  • Wuben(務本) :台灣市場能見度高，保固相對完整（部分款式 5 年），TIR 光學透鏡表現不錯。C3 等入門款價格親民，適合想買「有品牌感」又不想花太多錢的人。
  • Klarus（凱瑞茲）：雙尾按等戰術開關設計有特色，適合有自衛／戰術需求的人。
  • Skilhunt :小眾高品質，輕量與高效驅動電路出色
  • Cyansky :專注於戶外、戰術、狩獵與 EDC 照明產品，較冷門。
  • 其他-Convoy :主要為店家保固，超高性價比是DIY玩家最愛，價格極低但需自己搭配電池與充電器。

玩家級(海外/中國寄送)

這些是屬於自行到海外平台(如蝦皮海外、AliExpress等購買)。

  • Sofirn(索菲恩) :網路直銷為主，規格強、價格低，常附電池與充電線。介面多半簡單或使用開源 Andúril 韌體（可高度自訂）。適合想快速體驗「真的很亮」的人。
  • Wurkkos：與 Sofirn 關係密切（製造端重疊），產品線豐富，磁吸尾蓋、USB-C、高 CRI（顯色指數）版本多。
  • 其他-asafee/yemao等 :小品牌與貼牌，基本功能優於普通賣場手電筒，價格比五金行/一般大賣場筒更實惠又好，但品控、可靠度僅好於一般白牌貼牌水準(就優於傳統貼牌，但沒優到品牌筒/玩家級貼牌的程度)，以個人經驗來說是值得嘗試的入門筒。

這是選擇一支手電筒最基本的考量點，也是大多都忽略的

手電筒最基本：光班與熱點

光班整體圖，它通常分成三個部分：

  • 熱點（Hotspot）：正中央最亮、最集中的那一圈。
  • 過渡區（Corona / Transition）：熱點外圍亮度逐漸下降的區域。
  • 溢光／副斑（Spill）：最外圍的大範圍弱光區。

而 熱點 是光斑正中央亮度最高的那一塊區域，決定射程的關鍵。

  • 熱點越亮、越集中->對比強烈、光強（candela）越高 → 照得越遠外看的也越遠。
  • 熱點越大、越散：近距離更均勻，但遠距能力下降。

需探討一個問題： 人眼視覺限制

  • 當熱點很大、很亮時，眼睛會以熱點為基準降低整體敏感度。
  • 結果：周圍較暗的物體（遠處目標）變得更難分辨，甚至幾乎「消失」。
  • 這就像相機對準強光後，暗部細節全被壓黑一樣。

小而集中的熱點雖然局部很刺眼，但因為佔視野面積小，眼睛整體適應幅度較小，反而能保留更多周圍與遠處的細節。

所以

  • 熱點太大、溢光太多 → 背景也被照亮 → 對比下降 → 遠處物體輪廓變模糊。
  • 熱點小而集中 → 目標被強烈照亮、背景相對較暗 → 對比高 → 更容易辨識。
因此，絕對不要只看品牌筒的lm與射程都很高->就認為越亮越遠就是最好的手電筒(X)，這就是盲狙的一個現實問題，理想的什麼都要基本上是不可能的。

請參考：

  • 入門指南-品牌筒的快速實戰(cd/lm)。
  • 進階指南-cd、射程、lm、輝度與矽膠果凍。

實用建議：

  1. 可搭配輝度、cd/lm來判斷遠射狀況，通常lm越高時如果筒身反光杯不夠大時，遠射效果肯定不如預期。
  2. 參考國外手電筒網站資訊分享，及實測數據。

手電筒主流-反光杯與TIR透鏡。

反光杯：

反光杯靠拋物面反射，光線角度分布較「自然」且連續。深杯會把大部分能量壓進很小的熱點，其餘光線以較大角度散出，形成明顯的過渡區與溢光。

所以熱點小，但整體有用光斑看起來比較大。

相關變體：

  • 橘皮反光杯：
  • 橘皮反光杯是指反光杯內表面經過特殊處理，呈現像橘子皮一樣細微凹凸的紋理，而不是完全平滑的鏡面。把原本銳利、容易出現瑕疵的光斑「打散」一點，讓光線分布比較柔和、均勻，特性仍然是反光杯。
  • MVB反光杯：
  • 這是源自SureFire的一個專利，採用小口徑用多面切割+稍大口徑用連續縱向起伏的特殊反光杯結構，能再打牆時感受不太到熱點刺激，光線會變得比正常的反光杯均勻且舒適，也因此這種反光杯射不遠，以CQB、EDC等近距離照明為主。


TIR透鏡：

TIR 透鏡用全反射 + 折射把光線「強制」導入特定角度範圍。它比較像準直器，會把光集中在一個較明確的圓錐角內，邊緣下降較快。溢光雖然實際比反光杯大，但也因為邊緣下降快緣故，稍有距離時會幾乎看不到溢光的部份。

結果是，熱點被設計得比較大、比較可用，但整個明亮區域被限制在較小的角度內，所以外光斑看起來偏小。

相關變體：

  • 蜂巢TIR透鏡：
  • 結合了TIR透鏡與蜂巢狀表面紋理設計，這打出來的光幾乎看不到明顯熱點，是拿來用作工作燈/近距離照明用途，以Armytek Wizard系列的燈最常見，非典型玩家戶外照射用途。
  • TIR-R Lens/TIR-Fresnel(菲涅爾化TIR透鏡)：
  • 特點在於有個微型菲涅耳折射齒或相關折射區結構，透鏡造型上有非常多的環，這種在側向的光能捕捉打直(折射準直)，光斑上又會比一般TIR更集中外還能減少厚度，在小燈上來說能達到了不錯遠射照射效果。


實用建議：

  1. 若以遠射作為考量點，同lm與照射距離下，反光杯的小熱點特性效果會優於TIR本身。
  2. 以日常走夜路可能會照到對方眼睛的情境來說，TIR的光斑收斂特性較適合用於夜路探索。
    (要注意:有些TIR本身就設計不良，LED沒被TIR完整包覆會導致溢光程度跟反光杯差不多，所以最好要看實際拿到手電筒時的光斑呈現再決定。)
  3. 蜂巢TIR、MVB反光杯、菲涅爾化TIR透鏡這類偏向特定用途，最好資訊確認後再挑。

當自己大概摸清楚要選擇遠射or近距離的手電筒時，cd/lm是一個能避免過度盲狙的避坑指標。

了解cd/lm(遠射/近照明基礎)：

 cd/lm = 峰值坎德拉 ÷ 流明數

它代表「每一流明能轉換成多少遠射強度」。

  • 數字高 -> 光很集中，熱點銳利，遠射能力強。
  • 數字低 -> 光比較分散，溢光多，偏向泛光。

這個數字的好處是：它把「總亮度」的影響排除掉，讓你能比較不同流明的燈，誰比較會丟遠。

而且廠商有時亂寫cd時，透過此方式可以發現到問題。(參考底下的「判斷技巧2」)

例子：

A 燈：2000 lm、80,000 cd
→ cd/lm = 80,000 ÷ 2000 = 40
B 燈：3000 lm、60,000 cd
→ cd/lm = 60,000 ÷ 3000 = 20

A 燈雖然流明較低，但遠射效率明顯比較高。

判斷技巧:

  1. 先看 cd/lm，再看絕對cd。 cd/lm高代表光學效率好；絕對 cd 高才代表真的打得遠。
  2. 從各檔位得知的lm與cd中，看各自cd/lm有無嚴重落差。
    EX：假設每個檔位的cd/lm落在3~4浮動之間，但有個檔位的cd/lm卻有12的大落差，就要注意規格寫的可能不是真實數據。
  3. 搭配光斑來看:
    cd/lm 高 + 熱點小而銳 -> 真正的遠射型。
    cd/lm 高但熱點很大 -> 規格參數問題或是比較的光學系統不一致，導致不如判斷預期。
  4. 注意測量條件：即便可能各檔位cd/lm差異不大，但原廠規格仍可能會灌水，最好多參考手電筒論壇實測數據。

人眼可視距離限制：
普遍cd/lm>70的ANSI距離除2(終點距離從0.25lux退到1lux)能得到一個大致的有效可視距離，而如果是近距離、中距離則需要除3或除4，終點距離只會退更多。

 所以不可能有眼睛能看到的距離=手電筒ANSI距離。

大賣場中這類手電筒佔據最多，有大lm的跟便宜的一些有的沒的，但這是一個很糟糕的坑，下面講解。

這種光學環境下，最理想的情況應該要：

  1. 圓形LED小又亮(更強的輝度、不影響視覺的圓形投影、小發光面積減少側向光線損失)
  2. 更大的魚眼變焦燈頭，減少側向光線損失
  3. 採用定焦+小又亮的圓形LED，凸透鏡很貼合在LED打出的中心光，光損比變焦更小外還更靠得住防水。
    (伸縮變焦的IP防塵水更多只有參考性質，可能不如定焦手電筒的IPX4防水)。

即便是理想的情況，射程只會在400M以內，如果是XHP這類燈珠的話，射程只會更慘。

這是市售看過採用出光效率最好的，「定焦凸透鏡LED」照射該有的樣子，如果你手上的魚眼變焦在集中時沒有這圖的光線，或是外光斑都是偏暗的紋路溢光，那就是有光被筒身吃掉了，也就是我說的「發熱與光損」。

買越多以為看起來會不同，結果每個看起來都差不多，這就是它的真正雷區，永遠挖不到適合自己的好貨。

LEP雖然也是採用凸透鏡技術，但那是透過藍光LD投射到螢光體(凸透鏡)，螢光粉吸收激發後轉換出白光，再透過凸透鏡激發出去，與LED直接用凸透鏡打出去的完全不同。光效率與熱點完全勝過魚眼變焦手電筒，甚至是遠射手電筒的核心考量。

實用建議：

  1. 如果不清楚自己想要什麼手電筒，請避開選擇有凸透鏡的手電筒(包含LEP)。
  2. 魚眼變焦透鏡看起來很好，但實際照明效果最有限，最遠照射距離都不高。
  3. 日常選購手電筒或燈，請優先考量COB、DIP LED(傳統草帽LED)、反光杯、TIR透鏡這類立場鮮明的燈。
  4. 有遠射強熱點需求請直接買LEP，別為了省錢去嘗試各種凸透鏡的手電筒。

我相信有些買手電筒的玩家不是為了手電筒的興趣而買，而是因為相關事件去買的，但這裡我必須講一下：

高lm的手電筒，無法致盲。

選購手電筒的目的若是為了防身，那會犯下一個非常嚴重的錯誤，那就是你打出了光，打到對方眼睛以為這樣可以致盲，但是對方反而眼睛沒閉上，你手電筒的光線反而會變成活標把，也被捲入事件內。

我之所以這麼確定，是因為我真的拿眼睛實測過：

  1. 以室內昏暗光線模擬戶外昏暗狀況，並且與手電筒離1米照射距離(室內光線有漫反射+1M距離，以致盲防身目的來說已經很理想了)。
  2. 以EX7，分別打開3500lm爆閃、3000lm搜索檔、6000lm分別嘗試，cd最高60000左右。

你猜怎麼著?

  1. 這3個檔位下，我其實都能張開眼睛行動。
  2. 而且雖然眼前有個手電筒打出的光牆，但其實幾秒內就能適應，就是看不到細節這樣，但大體完全知道。
  3. 並且可以朝向手電筒方向移動，這會導致持有手電筒的人被攻擊。

這是我在手電筒最理想的致盲環境下測的，如果我都能給出這3個評價時...

那對於腎上腺素更高的殺人犯、強盜等，你手電筒打開就以為對方眼睛就看不到??未免太天真了。

那手電筒防什麼?

以EDC來說，手電筒的爆閃、流明盾這類光牆功能做的事情就只是:製造眼睛適應的緩衝時間。

  1. 前面說了，「其實幾秒內就能適應」，但反過來想，你可以利用這幾秒內的時間製造一定程度驚嚇+適應時間，進行逃跑以及求救嘗試提高生存率。
  2. 爆閃或流明盾之後，你必須做出戰術回應(用手腳癱瘓對方或是快速轉角逃跑)，不能待著。
  3. 白天場合光線效果會稀釋掉，所以只適合晚上防身用途。

那是否有可以致盲的手電筒?

有，以閃光彈為例，它可以致盲的關鍵就是超級高的坎德拉(cd)，以我實測的手電筒Convoy L21B SFT40(395000cd)就是會痛苦睜不開眼睛的程度，我是先預估100000cd可以達到一點致盲效果，但也要熱點射到眼睛才有用，所以這裡並不推薦用遠射筒來防身，更不推薦為了很好的致盲用途而浪費錢。


整個總結：

必須說，手電筒用作防身其實是屬於非常手段且知道接下來要幹嘛時才會有用途。
否則就以北捷長刀瘋子事件來說，他的長刀致死半徑可以直接在你拿出手電筒致盲前攻擊，而就算你成功拿出手電筒致盲了，那腎上腺素反而更容易成為活標靶，若沒有後續戰術手段那就是相當於送死的程度。

所以我很認真的說：若要防身請優先準備品牌辣椒水等合法防身武器，只有這種效果是比較好的（仍需注意相關規範以及使用問題，這裡不多講）。手電筒僅做為基本照明以及臨時的眩光來達到一點干擾用途(用下即行動)，也是爆閃設計目的。

lm是一般人都認識的，也是很多人都有一個越高越亮的誤解。

lm（Lumen，流明）

  • 定義：總光通量，也就是光源「全部發出的光」加總起來有多少。
  • 特性：不考慮方向，只看總量。多燈珠可以因此增加lm。
  • 白話：這顆燈總共「產生」了多少光。
  • 限制：流明高不代表照得遠，也不代表中心亮，因為光可能被散得很開。如同戶外人家1000lm的手電筒能看到眼前物品，就算拿真的3000lm也不見得看得到。

cd（Candela，坎德拉）

  • 定義：發光強度，指在「特定方向」上的光有多強。
  • ANSI/FL1 用法：取光束中最亮的那一點（通常是熱點中心）來測量。
  • ANSI公式: d(公尺)=√(cd/0.25)，最原始的是lux=cd/d²，ANSI以0.25lux作為最終照度。
  • 白話：熱點中心到底有多「刺」、多集中，cd 才是決定「能打多遠」的核心數字。
  • 限制：如果lm暴力性上升可以堆cd進而推導ANSI射程，實際上人眼反而會受到強光影響而大幅降低可視距離，此時的cd與ANSI射程在遠射上參考性很低。
  • 請參考->手電筒入門指南-基礎知識(光斑特性，非常重要) 之 加碼探討:人眼視覺限制。

輝度（Luminance）

  • 定義：單位面積的發光強度，單位是 cd/m² 或 cd/mm²。
  • 本質：光源表面有多「濃」、多「刺眼」。
  • 白話：LED 本身有多「密集明亮」。輝度越高，越有遠射天分。

 重要性：

  • 輝度是決定「能不能做出高 cd」的根本條件之一。
  • 同樣的總流明，如果發光面積小，輝度就高，比較容易被光學系統集中成小而亮的熱點。

同發光面積，有無果凍對LED輝度影響：

 矽膠果凍的設計目的與變化：

  1. 矽膠果凍的設計目的在於GaN層晶粒與空氣折射率差很大，光子在介面發生全反射而無法逃出，加上形狀與折射率合適的果凍(矽膠)後，臨界角變大，更多光子能以較接近垂直的角度逃逸，因此總lm通常能提升10~20%左右。
  2. 矽膠果凍有放大作用，會把晶粒的有效發光面積「撐大」。

  發光面積變大、光子順利逃逸 → 同樣的光被分散在更大面積上 → 輝度下降。

 去果凍、無果凍目的與變化(主流燈珠)：

  1. 有效發光面積接近真實晶粒尺寸，以及光子在介面全反射機會更大，導致總lm比起矽膠果凍下降10~20%左右。
  2. 氮化鎵(GaN)層、螢光粉層及側壁介面間產生多次全反射(TIR)與回收機制，晶粒表面更亮。

  接近實際晶粒大小、光被壓縮在更小的面積上、光子在介面間多次反射回收 → 晶粒表面更亮 → 輝度明顯上升。


 輝度總結：

  • 輝度低（發光面積大）的光源，即使總流明很高，也比較難做出極致的遠射。XHP50/70、SST70這類高lm代表就是屬於輝度低這類，若要達到遠射條件->燈頭與反光杯會需要更大尺寸來彌補自身短版。
  • 即便是SFT70這類無果凍的燈珠，輝度也無法與SFT-25R比較，畢竟SFT70發光面積大仍然是lm取向，無法與SFT-25R這種極小發光面積爆發的高lm並論。
  • 無果凍設計的代價就是能量與光效(lm/W)損耗較高，回收並非100%完美轉出，相對熱能損耗會比較高，對於追求lm與光效來說果凍版更適合。

沒研究很深，但勉強可以講些

SMD:

  • 這是目前的主流手電筒所採用的燈珠，很多經驗包括不限於3535等尺寸、去果凍、SST40與XML2比較等等，都是針對SMD封裝技術下的LED來寫的。
  • 這類封裝也應用在主流燈泡、側燈上。
  • 有一種比較特殊的，就是賣場便宜容易燒壞的強光LED，就是圓形透明塑膠SMD的LED(搜High Power LED容易看到)，這類時常被接3顆AAA-4.5v電池且無散熱，所以很容易導致嚴重發熱燒毀，這High Power LED與主流SMD LED差別在擁有獨立的凸出接腳與底部大面積金屬導熱散熱墊，美國大兵仿MX991的彎頭手電筒LED也都用那種(說明而已，我不推薦購買)。
    這整個頁面大部分所講解的，都是以主流SMD為核心出發，基本上不參考其他類型燈珠的光學表現。

DIP:

  • 多為5mm LED，又稱傳統LED，特色就是2根短長針腳與塑膠砲彈型或草帽型來包覆封裝，在大創的3LED或五金行的9LED都屬於此類燈珠。
  • 本身就是自帶凸透鏡的發光體，會有甜甜圈光斑跟暗區。但這封裝是塑膠整個包覆，相較SMD可以減少光學元件外燈珠本身防護能力也很高。
  • 這類燈珠雖然沒辦法應對更亮手電筒的要求，但在低亮度下狀況又好過SMD的手電筒，所以鑰匙燈多少還有DIP LED的產品，用這照明一直是經典。
    尤其CR2032+白光DIP LED的作法，可以在有限光源下點亮1週以上。

COB:

  • 多顆晶粒直接貼在基板，整片螢光粉覆蓋，所以lm理論上可以很高。但對於手電筒來說無法用作EDC的距離照明，所以多半做成側燈供露營、近距離使用，少數因應工作燈需求會做成主燈，如Asafee K01。

CSP:

  • 這其實是屬於SMD的其中一種，但與手電筒主流採用的地方不同在於封裝方式，CSP的封裝非常接近發光面積大小，目前確認Wurkkos TS10就是採用CSP2323封裝。
  • 以封裝來說，接近主流手電筒的無果凍特性，不過CSP本身打線在底部不在正面，且本身的立體分層讓DBR反射率非常高，輝度的能力理論會強於一般的無果凍燈珠。
  • 這類設計也讓打線熱組極低+導熱強，更耐大電流抗飽和能力，也就是極限超頻可以超的很高。
    但因為如此，直驅電路中需要特別限制CSP的表現，否則會太衝燒毀，這是Wurkkos TS10因為直驅所以有不少的燒毀案例後，新版限制了50% FET調降輸出表現。

其他非LED但也是主流之一的，也就是LEP，這類其實是透過藍光LD投射到螢光體(凸透鏡)，螢光粉吸收激發轉換出白光後透過凸透鏡激發出去，這並非討論LED種類範圍內。

不少人已經知道高顯色與RGB相關用途，但這裡會整理再講下，甚至說些比較少人知道的(或許?)。

白光的高顯色燈珠：

這是最多人探討的部份，高顯色通常都指CRI90燈珠，這能讓週邊的色彩要更突顯出來，否則顯色太低往往畫面都是偏向有些灰白、一片死白的樣子，這就是高顯色燈珠的優勢。

  • 低顯色（Ra 70）：綠／紅不夠，皮膚、血、食物、布料會偏假。
  • 高顯色（Ra 90+）：紅綠資訊較完整，辨色準。

高顯色燈珠不管在室內化妝或裝修，室外如果需要辨別色彩的時候高顯色的重要性都很高。
 但，高顯色有些問題：

  1. 高顯色的秘方在螢光粉，要打出鮮艷的顏色時深紅與深藍(紅是重點)這類不敏感的顏色會需要更突顯，也就是說在藍光轉換這些顏色出來時能量損耗會比低顯色高，也間接變成它不是大lm與好的光效選擇，遠射能力上也會比較差。
  2. 承耗電部份，發熱也是高顯色的問題之一，因為高顯色靠的紅粉不太耐熱，導致溫度一高時紅色會先掉，變得偏綠或冷色的情況，而這也間接導致燈珠更耗電。
  3. 因螢光粉特性，通常色溫越低才越容易有CRI90的燈珠，以主流日亞519A 9080來說色溫主流5000k，最高5700k，非主流的CSP2323才比較容易看到高色溫下CRI90的情況，而其他通常要4000k以下才比較容易有CRI90的燈珠(要注意:這裡不代表低色溫=高CRI，這要看廠商燈珠狀況)。
  4. 另外，CRI越高不代表顏色能正確突出，這個還要看R9的部份(飽和紅色)，以燈泡來說有些廠商像519A 9080就有提供R9≥80這個數值(>0是基本，不能負數)，就是針對紅色的表現，對高顯色有要求的需要注意。

所以，高顯色燈珠雖然有很多人吹捧與跟進，但在目前的主流選擇中，適當的CRI選燈才是比較好的，尤其戶外場合上cd/lm的考量反而會比有無高顯色還更重要。

關於cd/lm，請參考最後一篇：品牌筒的快速實戰(cd/lm)。


RGB燈色：

雖然已經不少持有手電筒玩家都知道RGB的相關作用，但有新手可能認為跟電腦主機的RGB甚至是與我字體的RGB是差不多的，這個就不完全對了。有些RGB燈自帶流水燈效果雖然屬於娛樂性質，但切到單一燈光時就會有用途，甚至是單一色彩的手電筒用途會更明顯~~我講一下。


紅光算是玩家比較熟悉的，因為這類光線的特點就是波長很長、能量低，對視桿細胞刺激較弱，所以：

  • 暗適應破壞最小（天文、夜行、戰術接近）。
  • 多數昆蟲較不趨光。
  • 穿透霧氣中等，但總亮度感偏低。
  • 觀感上看起來會不夠亮，其實是人眼對紅光不敏感，不是燈壞了。

因此，紅光也是被多數人認知且用途廣泛的燈，在戶外想要夜視不影響其他昆蟲或是不想毀掉自己的夜視狀態，那紅光會更重要。


橙光或黃光，在紅光的場合中想要顏色時這類會是比較好的折衷方案：

  • 這類燈珠主要是藍光+特製螢光粉激發，本質上接近於白光LED，不過比白光少藍光，眩光較低，且比紅光亮、細節較好。
  • 煙、霧、灰塵裡對比有時比冷白好（散射較少）。
  • 僅少數橙光是自己發光，因為亮度與效率通常較低，所以多數包含Weltool M7-AM都是採用藍光+螢光粉製成的，不建議特別找自發光版本。

對於只有黑白紅色彩的紅光來說，橙光可以減少昆蟲驅光性外，也能達到部份狩獵用途，屬於折衷且很好的替代方案。


綠光是人眼最敏感的光線，主觀上往往比紅、藍都「亮很多」：

  • 純正綠光的光譜窄顏色純，但在高電流、高溫時效率變差外，也會有像藍光方向偏移的問題。
  • 有種叫琥珀綠的燈，就是如同橙光的技術，採用藍光+特殊螢光粉製成的綠光，在顏色、光效上會比純綠光好。
  • 高靈敏且綠色對於部份動物來說不敏感(像是豬，不過有些動物含掠食者對綠光較敏感)且草叢地形對比較自然的特性，狩獵會用到綠光比較多。

對於一般玩家來說，琥珀綠其實在視覺靈敏度拉高的同時也享受到一點藍光擁有的色彩，日常使用會更適合。純正綠光更多作為信號或是狩獵等特定用途會比較好。


藍光是現代LED最不可或缺的，但這裡說的是藍光本身，對於一些用途還是有的：

  • 短波長、散射強、容易刺眼，對暗適應破壞大。
  • 通常用作取證，查看血液、體液、部份纖維的光線反應。
  • 因為本身光線不友好，在取證時常搭配橘／黃濾鏡護目鏡看螢光反應。

所以，純藍光更多只做為取證相關或特定夜釣行為，日常用途比365nm UVA燈要少很多，因此一般玩家是不太需要考慮這類手電筒。



其他燈色：

UV(365nm UVA)紫外線燈是目前主流EDC系列手電筒可能會附加的燈泡，看似少用但用途很高的特殊燈：

  • 使用這類燈的目的並不是看發出的紫光，而是看照到東西時激發的螢光反應，因此有些手電筒會在UV燈那邊加上ZWB2的黑色濾光片，這會大幅突出螢光效果。
  • 不只能照鈔票辨認真偽，琥珀蜜蠟鑑定、寵物貓癬（螢光反應）檢測、居家防霉、廚衛漏水檢測等都能透過螢光反應判斷。

UV燈雖然日常場合中比較少開，但在遇到需要螢光判斷而要開不可的時候，這燈往往是重要的，也是EDC常有、少用但一用會很實用的燈。
